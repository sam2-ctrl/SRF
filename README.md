# Screener + ChatGPT Connector

This project lets you type a company name and get:
- core company details from Screener
- quarterly results parsed from Screener
- a clean AI summary generated by ChatGPT

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Set your OpenAI API key:

```bash
export OPENAI_API_KEY="your_api_key_here"
```

## Usage

```bash
python screener_chatgpt.py "TCS"
```

Or with a company name:

```bash
python screener_chatgpt.py "Infosys"
```

Print parsed raw data (no GPT summary):

```bash
python screener_chatgpt.py "TCS" --raw
```

Use a different model:

```bash
python screener_chatgpt.py "TCS" --model gpt-4.1
```

## Notes

- If a company URL cannot be found automatically, try the exact Screener company code.
- This script is for informational use only, not investment advice.
